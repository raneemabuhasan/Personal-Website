# Hero Arabic watermark

Text: رنيم أبوحسن

`arabic-name.json` contains Amiri Regular glyph outlines, shaped as a complete
right-to-left phrase using CoreText. SVG paths preserve Arabic contextual forms,
connections, and the hamza in أبوحسن without loading a runtime font.

The handwriting-style masks use centerline guides derived from the shaped
outlines, ordered right to left with structural strokes before shorter marks.
They approximate pen movement; they are not a recorded calligrapher's ductus.
The visible silhouette always comes from the original outline, not the mask.

Source font: https://github.com/google/fonts/tree/main/ofl/amiri
